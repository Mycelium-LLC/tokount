# tokount 0.1.0: the first public release

**What a user sees change:** `npx tokount --handle <name>` works on macOS, Linux and Windows without ccusage, and its numbers match ccusage. A new `--dry-run` shows the numbers and publishes nothing, and `tokount doctor` says what was found. The landing at `mycx.dev/tokount/` puts the command in the first screen, shares with a real preview image, and is in search. Each person's page shares with an image of their own numbers and stays out of search.

## Not in this release

- A cache of per-file results, which would make a second run near-instant on very large histories.

## Check it from a fresh clone

```bash
git clone https://github.com/Mycelium-LLC/tokount && cd tokount && git switch release/0.1.0
npm test
```

Expected: `# pass 4 # fail 0` (service), `# pass 15 # fail 0` (CLI), then `npm pack --dry-run` listing 13 files, about 16 kB. Failing looks like any `not ok` line.

```bash
cd package
TOKOUNT_TELEMETRY=0 node bin/tokount.mjs doctor      # each reader: found / not found, counts, no paths
TOKOUNT_TELEMETRY=0 node bin/tokount.mjs --dry-run   # the summary, then "Dry run: nothing was published."
node bin/tokount.mjs --version                       # tokount 0.1.0 (dev) from a clone; the commit after npm publish
```

The service with an in-memory store: `node service/src/server.mjs` needs Firestore credentials; for a look without them, run `createApp({ store })` with a Map, as `service/test/seo.test.mjs` does.

## Deploy

1. Merge the release PR with a merge commit, pinned to the QA'd head.
2. Tag `0.1.0` on the merge commit and push it: `publish.yml` publishes `tokount` to npm. The very first publish needs Niko's npm login on this Mac (`npm publish` from `package/`), because Trusted Publishing can only be linked to a package that exists; link it right after, for 0.1.1 on.
3. `deploy/deploy.sh` from a clean checkout of the tag: deploys the service and checks `/tokount/version.json` and `/api/health` state 0.1.0 and the commit.
4. Ship mycx-hosting 0.1.4 (the route, robots, sitemap), whose smoke checks `/tokount/` and `/api/tokount/health` through `mycx.dev`.
5. Register HQ Ops tenant `tokount` (route probes, the `tokount-web@` identity).
6. `npx tokount --handle nikotsy` from a clean shell; then `https://mycx.dev/tokount/nikotsy` is live.
7. `gh release create 0.1.0 --verify-tag --title "0.1.0 — public release" --notes-file docs/qa/0.1.0.md`.
