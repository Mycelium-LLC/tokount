## What changes for someone using it

- The tab icon on `mycx.dev/tokount/` and on every person's story page is tokount's own mark: a lime "t" on ink with
  the violet orb. Until now the tab showed the full Mycelium wordmark (1312×241), which was unreadable at 16 px.
- Adding the landing to a phone's home screen gives the same mark (180 px `apple-touch-icon`, 192/512 px manifest icons).
- `deploy/deploy.sh` reads `version.json` past the CDN and fails loudly on an empty answer. It also checks the four icon files live.

## The mark, and why

- **A lowercase "t" from Bricolage Grotesque ExtraBold.** It's the hero's typeface and weight ("Meet **tokount.**"),
  so the icon is the headline's first letter, not a new drawing. The glyph is the font's own outline (OFL, already in
  `service/fonts/`).
- **Lime on ink.** Lime is the landing's action/command colour, and ink is its ground. Lime on ink has the highest
  contrast in the palette, and that's what survives 16 px.
- **The violet orb bleeds off the top-right corner**, like the landing hero's orb (`.orb`, `inset-inline-end: -23vmax`).
  It overlaps the "t"'s crossbar, so the two read as one shape at 16 px.
- **Rejected:** three bars of growing length on violet, which reads as a generic list or menu icon at 16 px. And a lime
  `>_` prompt on ink, which is a stock terminal icon that fits any CLI. A first "t" draft with a smaller, inset orb lost
  the orb at 16 px. Concepts came from a Codex image sheet first, then were redrawn as SVG and judged on light and
  dark tab strips at 16, 32 and 180 px.

## Code

- `service/brand/icon/`: `favicon.svg` (rounded, 64-unit grid), `favicon.ico` (16 + 32), `favicon-32.png`,
  `apple-touch-icon.png` (180, full-bleed: the OS draws its own mask), `icon-192.png`, `icon-512.png`, `manifest.webmanifest`.
- `service/src/app.mjs`: serves each icon at `/tokount/<name>` (a day's cache), before `/tokount/:handle`.
  Those names, plus `brand.svg`, `og.png` and `version.json`, can never be claimed as a handle: until now
  `--handle og.png` passed the pattern and made a page nobody could reach.
- `service/public/index.html` and `service/views/story.html`: `icon` (.ico + .svg), `apple-touch-icon`, `manifest`.
  The CLI renders no HTML (the service renders each story), so there's nothing to change in `package/`.
- `deploy/deploy.sh`: `version.json?v=<commit>` cache-buster, a loud failure on no answer or an empty one, and live checks for the icons.
- Versions: `package.json`, `package/package.json`, `service/package.json` (+ lock), JSON-LD `softwareVersion` → 0.1.1.
