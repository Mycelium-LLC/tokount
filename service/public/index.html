The privacy promise.

What leaves.

When you publish: a derived summary of totals, dates, model names and patterns. Project and folder names are never collected. A publish and doctor also send anonymous run counts (version, OS, records read, an error code); TOKOUNT_TELEMETRY=0 or DO_NOT_TRACK=1 turns them off. A dry run sends nothing.

What stays.

Your prompts, responses, code, transcripts, file paths and project names never leave your computer.

What expires.

The public page goes offline after 30 days. Run the same command again to update it and restart the clock.
